# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is published here:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be respectful and constructive. We want participation in this project
to be a harassment-free experience for everyone, regardless of background or
identity.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
project maintainer at **inkcartridge@cristimilea.ro**. Reports will be handled
confidentially. The maintainer is responsible for enforcement and may take any
action they deem appropriate, up to and including a ban from the project's
spaces.
